# HIMUR GLOBAL HUB — Sections 01–08

A modern B2B garment marketplace frontend designed for global buyers and verified garment manufacturers.

This repository contains Sections 01–08 of the planned 15,000px master homepage.

## Project Structure

- `index.html` — Main page structure
- `css/style.css` — Visual styling and responsive design
- `js/main.js` — Loader, mobile navigation, scroll reveal, counters and demo interactions

## Run Locally

1. Keep the folder structure unchanged.
2. Open `index.html` in a modern web browser.
3. Internet access is required for Google Fonts, Font Awesome and remote Unsplash demo images.
4. For development, VS Code + Live Server is recommended.
[Visit Live Website] https://rifat-mia110806.github.io/himur-global-hub/
## Important Notice

All manufacturer names, statistics, email addresses, images and verification-related content are demonstration data.

Replace all demonstration content with real, legally verified business information before publishing the website commercially.

The following systems are **not implemented in this frontend**:

- KYC / identity verification
- Passport / national ID verification
- Face verification
- Payments
- Escrow
- AI-powered translation
- Authentication
- Database systems
- Legal and compliance workflows

These features require a secure backend, database infrastructure, authentication, approved third-party service providers and appropriate legal/compliance review.

## Current Scope

This project currently includes **Sections 01–08** only.

Each section is being designed and reviewed individually before the next part of the homepage is developed.
